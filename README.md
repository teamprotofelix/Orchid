# ORCHID ATELIER v2.0 — 난 상태 비교 · 관리 가이드 · 나의 난 일기장

브라우저에서 바로 실행되는 순수 HTML/CSS/JavaScript 기반 정적 사이트입니다. **GitHub Pages에 업로드 가능하며 별도 서버, 로그인, API 키, DB, 라이브러리 설치가 필요 없습니다.**

## GitHub Pages 배포

1. ZIP을 압축 해제하여 `orchid-care-site` 폴더를 엽니다.
2. **폴더 자체가 아니라 폴더 안의 모든 내용**(`index.html`, `.nojekyll`, `assets/`, `css/`, `js/`, `sw.js`, `manifest.webmanifest` 등)을 GitHub 저장소의 `main` 브랜치 루트에 업로드합니다.
3. GitHub 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
4. 배포 완료 후 `https://<사용자명>.github.io/<저장소>/` 주소로 접속합니다. 커스텀 도메인은 GitHub Pages에 별도로 지정합니다.
5. 첫 접속은 인터넷 연결 상태에서 완료한 뒤, 오프라인 기능을 확인하세요. 정적 파일 캐시는 HTTPS에서만 자동 활성화됩니다.

**업데이트 전 주의:** 이미 저장한 v1 데이터가 있다면 기존 사이트 주소와 브라우저를 유지해서 접속해야 자동 이전됩니다. 주소나 origin을 바꾸면 브라우저 저장공간은 공유되지 않습니다. 먼저 기존 사이트에서 JSON으로 백업해 두고 v2에서 복원하세요. 브라우저 기록 삭제·시크릿 모드·다른 기기 이동 시 로컬 일지가 없어질 수 있습니다.

- **증상 비교 25종:** 건강한 잎·뿌리, 건조, 뿌리썩음, 관부 부패, 황변/일소/냉해/반점, 바이러스 의심 무늬, 가루깍지/깍지/응애/총채벌레, 꽃봉오리 낙하, 개화 부족, 가구경 주름 등
- **8개 심화 관리 가이드:** 새 난 첫 2주 / 물주기 판단 / 뿌리·배지 검사 / 급성 부패 대처 / 해충 관리 / 꽃과 개화 / 계절 / 시비
- **8개 품종 구별:** 호접란, 심비디움, 카틀레야, 온시디움, 덴드로비움, 동양란, 파피오페딜룸, 반다
- **나의 난 일기장:** 여러 개의 난을 이름·사진·품종·위치·구매일·배지·화분별로 등록, 개별 이력 조회
- **관리 이력:** 실제 물주기, 비료, 분갈이, 해충, 새뿌리/새잎, 개화, 관찰 등의 기록, 작성·수정·삭제
- **상세 관찰:** 날짜, 배지, 뿌리, 잎, 빛, 온도, 습도, 메모 및 사진 첨부. 브라우저에서 소형 WebP로 변환 후 저장
- **달력·타임라인:** 날짜별 기록 수, 클릭으로 날짜 선택, 유형별 기록 필터, 마지막 물주기·비료·분갈이 날짜
- **백업:** 모든 난과 기록 및 저장된 사진이 포함된 JSON 백업·복원, 기록표 전용 UTF-8 BOM CSV 내려받기
- **기존 v1 기록 자동 이전:** 같은 origin에 v1 기록이 존재하고 v2 기록이 없을 때 최초 표시 시 이전. 이전 후에도 v1 키는 삭제하지 않습니다.
- **오프라인:** 서비스 워커 `v2.0.0` 캐시, 모바일 반응형 레이아웃, GitHub 프로젝트 하위 경로 지원

## 사진 처리와 개인정보

사진 비교 섹션에 올리는 내 난 사진은 **세션에서만** `blob:` URL로 표시되며 새로고침 시 사라집니다. 일기장에 선택한 프로필·관찰 사진은 브라우저 내에서 최대 640px로 줄이고 WebP(지원 안 되면 JPEG)로 압축하여 `localStorage`에 저장합니다. **사진과 기록은 서버로 전송되지 않으며**, 백업 JSON에는 사진도 함께 포함됩니다. CSV에는 사진이 포함되지 않습니다.

브라우저 저장 용량은 환경에 따라 제한됩니다. 저장 실패 시 기존 기록을 유지하도록 설계했지만, 사진을 다량 첨부하면 한도에 도달할 수 있습니다. 중요한 일지는 주기적으로 JSON 백업해 두세요. 최대 50그루·500개 이력, 사진 선택당 원본 18MB 제한이 있습니다.

## 관찰과 치료 주의사항

- **이 사이트는 병명을 자동 확진하지 않습니다.** 사진 25개는 AI가 생성한 실사형 **교육용 참고 이미지**이고 실제 병원균을 검경해 동정한 검증 사진이 아닙니다. 심한 부패와 바이러스 의심 증상은 전문가의 확인을 받아야 합니다.
- 잎 처짐은 건조뿐 아니라 **뿌리 부패**에서도 발생합니다. 물을 주기 전에 배지·뿌리의 촉감과 상태를 먼저 확인하세요.
- 검게 변한 뿌리도 단단하면 반드시 죽은 것은 아닙니다. 은백색 뿌리도 정상일 수 있습니다. 색만으로 절단하지 마세요.
- 악취, 진물, 급속히 확산하는 물 먹은 반점, 관부 무름이 있으면 다른 난과 격리하고 전문가에게 문의하세요.
- 살균제·살충제는 대한민국 해당 제품·작물·해충의 사용등록 여부 및 라벨을 확인합니다. 계피·표백제·세제 등 검증되지 않은 민간 혼합액을 식물에 바르지 않습니다.
- 품종·배지·화분·빛·계절에 따라 관리가 달라집니다. 물주기 후 ‘N일 경과’는 **과거 기록일 뿐 다음 관수를 지시하는 알림이 아닙니다**.
